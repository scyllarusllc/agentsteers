Prototype status: End-to-end iPad Voice → plugin → self-hosted Codex CLI is not yet demonstrated. Public access does not mean that OAuth or execution safety is ready.

THE FLOW

From a conversation
to a controlled coding task.

One secure entry point, one owner-managed server, and an explicit boundary before any task is run.

01 · TALKiPad / ChatGPT VoiceDescribe the development task naturally.
→
02 · AUTHORIZEAgentSteers MCPAuthenticate, check scopes and repository access.
→
03 · EXECUTEYour server / Codex CLIRun approved work and return sanitized results.

Planned architecture only. ChatGPT Voice tool support, Google OAuth, remote MCP integration, and live Codex execution require implementation and validation.

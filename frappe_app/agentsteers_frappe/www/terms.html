Terms of use

Last updated: November 8, 2026. This draft is provided for review and is not a finalized production agreement.

Current availability

AgentSteers is an experimental open-source project. The landing page describes intended capabilities. It does not promise a deployed voice-to-Codex service, availability, or compatibility with ChatGPT Voice.

Authorized use

Any future MCP integration should be used only on infrastructure, repositories, and accounts you are authorized to access. Never submit passwords, access tokens or other secrets through public project issues.

Risk and approvals

AI-generated code or actions may be incorrect or unsafe. Review changes and require separate authorization for production deployment, privileged operations, sensitive records, and destructive actions. The prototype should not be used as a production execution gateway.

Source-code licensing is governed by the license file in the GitHub repository, if applicable, not by this draft website text.

Questions

For project questions, visit the GitHub issue tracker. Formal service terms and operator details must be completed before offering a production login service.

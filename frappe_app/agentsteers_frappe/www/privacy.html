DRAFT — NOT YET A PRODUCTION POLICY

Privacy

Last updated: November 8, 2026. This page describes the proposed prototype, not a verified description of any live production processing. A final policy must be reviewed and published before enabling public Google sign-in.

Project status

AgentSteers is an open-source experimental project intended to connect an authorized ChatGPT tool to a coding agent running on an owner-managed server. The public landing page is static and has no Google login form.

Planned account information

When a future sign-in feature is implemented, Google OpenID Connect may supply an account identifier, email address, and basic profile information to identify authorized users. The project intends to request only the minimum necessary scopes: openid, email, and profile. The actual integration, retention schedule, and storage locations must be documented before launch.

Planned operational data

To enforce access permissions and support user-requested tasks, a future service may process repository identifiers, submitted instructions, job status, and access/audit records. Code content and task output may contain sensitive material and require explicit controls. Do not submit sensitive information to any unauthenticated prototype.

Data controls and security

The target design includes least-privilege permissions, token checks, task ownership enforcement, redacted logs, and separate approval for risky actions. These are design goals, not a claim that all safeguards are deployed today.

Questions

For project questions, open an issue in the AgentSteers GitHub repository. Do not submit private credentials in public issues.

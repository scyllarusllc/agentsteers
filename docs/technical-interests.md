## Primary direction / 当前主线方向

**Reliable and Controllable AI Agents for Real-World Workflow Automation**  
**面向真实工作流程的可靠、可控 AI 智能代理**

I am interested in **both** sides of AI agents: reasoning and planning **and** practical execution with tools, code, and verifiable outcomes. A useful agent should understand the intent, plan steps, take authorized actions, and check whether the task actually succeeded.

我对 AI Agent 的**规划思考**和**实际执行**都感兴趣。理想的智能代理应理解意图、拆解任务、在获得授权后操作工具或编写代码，并验证任务是否真正完成。

### Related projects / 项目组合

- **AgentSteers:** voice- or natural-language-directed software development and authorized Codex task execution; end-to-end cloud execution is still an integration goal, **not a verified deployed capability**.
- **Inboxtend:** self-hosted email workspace for understanding messages and tracking follow-ups/tasks.
- **OrbitMinder:** personal project overview and task tracking; the README describes an early prototype, not a deployed autonomous agent.
- **EZ Accounting / ERPNext:** real-world business workflows that could become future agent-assisted use cases.

### Reliability principles / 可靠性原则

1. Plan clearly / 明确规划
2. Respect permissions and human approval / 尊重权限与人工审批
3. Execute observably / 执行过程可观察
4. Verify results and report uncertainty / 验证结果并说明不确定性
5. Recover safely from failures / 失败时安全恢复
